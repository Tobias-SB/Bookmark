Bookmark spike bookmarklets

Throwaway test tools for spikes S3 and S4. They run only in your own browser tab, read the open AO3 page, and send nothing anywhere. This page has no scripts, no tracking and makes no network calls.

The two links

Spike capture
Reads the work title, tries to write it to the clipboard, and shows the result.

Spike count blurbs
Shows how many li.blurb entries the page has, and the page heading.

Install

Desktop Chrome or Firefox

  1. Show the bookmarks bar (Ctrl+Shift+B).
  2. Drag each link above onto the bar.

Android Chrome

  1. Long-press a link, choose copy link address (or tap the star after opening it) and add a bookmark; if Chrome refuses, bookmark this page, then edit the bookmark.
  2. Edit the bookmark: set the name, and paste the copied javascript: address as the URL.
  3. To run it: open the AO3 page, type the bookmark name in the address bar, and tap the bookmark suggestion that appears (Chrome ignores bookmarklets tapped from the bookmarks list).

iOS Safari

  1. Tap Share, then Add Bookmark, and save this page as a bookmark.
  2. Long-press one link, choose Copy Link (if offered).
  3. Open Bookmarks, tap Edit, open the bookmark you just saved, rename it, and replace its address with the copied javascript: text. Repeat for the second link.
  4. To run it: open the AO3 page, tap the address bar, then Bookmarks and tap the bookmarklet.

If nothing appears when you run it, record "nothing happened". That is a valid result (AO3's content security policy or the browser blocked it).
