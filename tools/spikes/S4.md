# Spike S4: which AO3 pages show work blurbs (spec §21 S4)

Uses the "Spike count blurbs" link from `tools/spike-s3/index.html` (install steps in S3.md). Easiest on desktop Chrome or Firefox; repeat on a phone only if S3 shows phones work.

## Owner steps

For each page type, open an example while logged in to your own account, run "Spike count blurbs", and record the blurb count, the heading text it shows, and where the list name appears on the page (heading, tab title, sidebar or nowhere).

| Page type | Example address pattern | Blurb count | Heading text shown | Where is the list name? |
|---|---|---|---|---|
| Your bookmarks | `/users/<you>/bookmarks` | | | |
| History | `/users/<you>/readings` | | | |
| Marked for Later | `/users/<you>/readings?show=to-read` | | | |
| Subscriptions | `/users/<you>/subscriptions` | | | |
| A series page | `/series/<id>` | | | |
| An author's works | `/users/<name>/works` | | | |
| Search results | `/works/search`, then submit | | | |
| A collection | `/collections/<name>/works` | | | |
| Another user's bookmarks | `/users/<name>/bookmarks` | | | |

For each page also note whether the count matches what you see (pagination means only the current page counts), and whether a series page counts series blurbs or work blurbs.

## Go / no-go

- Go: recorded per page. There is no pass or fail; the table decides which pages bulk update (Phase 2) and rec lists (Phase 4) support.
- No-go: document only the supported pages.
