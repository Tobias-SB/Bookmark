# Spike S3: bookmarklet under AO3's CSP, and iPhone clipboard (spec §21 S3)

Files: `tools/spike-s3/index.html` (install page) and `tools/spike-s3/bookmarklet.js` (readable source). The two links in the page are generated: after editing the source, run `node tools/spike-s3/build.mjs`. The page has no scripts, no tracking and no network calls.

## Hub to-do

- Phones need the install page over http(s). Copy `tools/spike-s3/index.html` to the S6 host (for example `public/spike-s3/index.html` before export). Do not copy `bookmarklet.js` or `build.mjs`. The page loads nothing external, so `require-corp` is fine.

## Owner steps

1. Open the install page and install the "Spike capture" link in each browser (the page has per-browser instructions): iOS Safari, Android Chrome, desktop Chrome, desktop Firefox.
2. Open any AO3 work page (`archiveofourown.org/works/<id>`) in that browser.
3. Run the bookmarklet. Note whether a white overlay appears, what it says about the title, and whether it says the clipboard was WRITTEN or FAILED.
4. If WRITTEN, paste into a notes app or the address bar and confirm the paste is the work title. On iPhone this is the key check.
5. If FAILED, check the text box in the overlay can be selected and copied by hand.
6. If nothing happens at all, record that (probably AO3's content security policy, or the browser blocking `javascript:` URLs).
